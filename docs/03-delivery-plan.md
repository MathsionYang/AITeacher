# MVP 交付计划

## 阶段 0：当前已完成

- 建立本地可运行原型。
- 内置人教版小学数学 3-6 年级上册客观知识点，并按年级、册别拆成独立 JS 知识包。
- 完成视觉化课件生成、生成中进度动画、完成后展示、审核编辑、审核稿保存、JSON 导入导出、PDF/Markdown/PPTX 导出。
- 完成默认空白的同步出题、AI 生成/重新生成、练习历史导入导出、答题判分、错题库、错题组卷、周期测验配置。
- 同步练习、错题卷和周期测验已限制在当前所选单元知识点范围内。
- 每套卷固定 10 题，总分固定为 100 分，并覆盖当前单元全部知识点。
- 完成分数段反馈：低分鼓励图、肯定奖状、撒花特效、领奖台动画。
- 完成成绩保存、趋势图和薄弱知识点分析。
- 增加 `mock-data.js`，测试数据与正式知识包分离，便于随时替换。
- 接入 `model-client.js`、`agent-orchestrator.js`、Node/Python 本地模型代理，支持可选模型连接测试、知识点课件页 AI 课件审核稿和同步出题页 AI 出题候选题。
- 新增 `login.html` 教师登录入口，学生登录按钮保留但暂未开放。
- 新增教师端班级管理、班级切换、学生添加/删除，以及账号/班级/学生/提交/生成记录本地数据结构。
- 教师端左侧导航调整为导学课件、同步出题、错题库、周期测验、班级管理、系统设置；模型、本地数据和 OCR 入口收进系统设置。
- 完成 PRD、系统设计、交付计划、版权合规、AI 课件规范、LLM/Agent 架构文档。

## 阶段 1：可演示 MVP

目标：让家长或老师能完整体验一次学习闭环。

工作项：

- 补齐 3-6 年级下册知识点包。
- 每个知识点沉淀 10-20 道原创题模板或可审核题目。
- 完善客观题型：选择题、填空题、计算填空题、单位换算填空题、数据填空题。
- 完善错因枚举：概念不清、计算错误、单位遗漏、审题错误、步骤缺失。
- 增加答题结果导出。
- 完善本地数据清理入口，支持清空账号、班级、学生、错题、成绩、审核稿、提交记录、生成记录和 mock 数据。
- 教师端保留 AI 生成、课件审核、题目审核、导入导出、班级管理、学情统计和数据清理。
- 学生端登录按钮先保留，待 Go/Java 后端账号、权限、作业和学生练习记录接入后开放。
- 扩充可替换 Mock Data 场景，覆盖低分、及格、高分、满分、错题复习和周期测验。

验收：

- 三到六年级上下册均有独立知识点包。
- 任意单元可生成固定 10 题、总分 100 分、覆盖全部知识点的练习。
- 所有练习题都只来自当前所选单元知识点。
- 错题库可按当前单元和知识点筛选。
- 周期测验可在当前单元内混合新题和错题。
- Mock Data 可通过替换 `mock-data.js` 快速切换测试状态。
- 教师可登录、切换班级、管理学生，学生入口提示暂未开放。

## 阶段 2：本地 OCR、模型和数据持久化

目标：保持无服务器部署，把 OCR、模型调用和本地数据保存封装到客户电脑上。

工作项：

- 桌面化或本地 Web 打包：Electron、Tauri 或本地静态包。
- 本地数据层：已新增 `storage-adapter.js` local-json envelope 和 SQLite schema/迁移计划；后续可替换为真实 SQLite 文件写入。
- SQLite schema 已预留账号、班级、学生、课件、试卷、题目、提交、OCR 记录、生成记录等后端表。
- 本地 OCR 适配：已新增 PaddleOCR 本地代理和前端调用入口；后续可替换 TrOCR、云 OCR 或客户配置的 OCR 接口。
- 本地模型适配：OpenAI-compatible 接口、本地代理或客户自有模型网关。
- 图片处理：仅在本机完成预览、识别和必要缓存。
- 数据导入导出：支持备份、恢复和迁移。

验收：

- 客户电脑离线或局域网环境下仍能打开核心功能。
- 学习记录、错题、成绩和审核稿可稳定保存在本地。
- 上传照片后能生成识别文本和判分结果。
- 低置信度题目已在手动校正面板中提示“需人工确认”，PaddleOCR 返回置信度会同步进入校正流程。
- 不依赖自建服务器即可完成学、练、批、讲、复测闭环。

## 阶段 3：AI 教研能力

目标：让系统从“能用”变成“好用”。

工作项：

- 深化课件生成：继续强化知识点覆盖检查、疑似教材原文检查和 PPTX 版式模板。
- 深化题目生成：增加答案验算、难度匹配、客观题型过滤、开放题拒绝和版权相似度检查。
- 解析生成接入大模型。
- 错因诊断和个性化复习计划。
- 教师端中强化审核题目和课件；学生端开放后接入班级作业、个人提交和发布审核流。
- 扩展 Agent 编排：补齐批改、错题复习和周期测验流程。
- 增加题目答案验算、客观题型、开放题过滤、版权相似度和单元边界校验。

验收：

- AI 题目必须可自动验证答案。
- 解析包含考点、步骤、易错点和同类题。
- 错题复习能按掌握状态调整题目比例。
- 教研人员可以审核和发布内容。
- 大模型输出不能越过已审核知识点和当前单元边界。
- 学生端开放条件清晰：后端账号、学生练习记录、布置作业、权限控制、发布审核、班级报告。

## 阶段 4：商业化扩展

目标：从小学数学人教版扩展到更多教材和学科。

工作项：

- 扩展苏教版、北师大版等教材版本。
- 扩展语文、英语等学科。
- 增加班级、教师、家校沟通。
- 增加学情报告和学习路径。
- 可选增加本地网络共享或学校内网部署。
- 增加支付、会员、机构管理。

验收：

- 多教材版本可配置。
- 多学科共用题库、错题和批改框架。
- 教师可管理班级测验和报告。
- 单机版、本地网络版和后续云端版可以共用核心内容结构。
