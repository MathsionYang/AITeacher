# MVP 交付计划

## 阶段 0：当前已完成

- 建立本地可运行原型。
- 内置人教版小学数学原创样例知识点。
- 完成课件生成、同步出题、答题判分、错题库、错题组卷、周期测验配置。
- 完成 PRD、系统设计和交付计划文档。

## 阶段 1：可演示 MVP

目标：让家长或老师能完整体验一次学习闭环。

工作项：

- 扩充 1-6 年级每册单元知识点。
- 每个知识点沉淀 10-20 道原创题。
- 增加题型：口算、竖式计算、填空、选择、应用题。
- 完善错因枚举：概念不清、计算错误、单位遗漏、审题错误、步骤缺失。
- 增加答题结果导出。

验收：

- 单个年级至少覆盖 8 个单元。
- 任意单元可生成 10 题练习。
- 错题库可按知识点筛选。
- 周期测验可混合新题和错题。

## 阶段 2：OCR 和后端

目标：从本地原型升级为可登录、可保存、可批改照片的 Web MVP。

工作项：

- 前端框架化：React/Next.js 或 Vue/Nuxt。
- 后端 API：用户、教材、题库、试卷、提交、错题。
- 数据库：PostgreSQL。
- 文件存储：对象存储保存答题图片。
- OCR 服务：接入图片识别、题号切分和答案提取。
- 队列服务：批改任务异步处理。

验收：

- 用户可登录并保存学习记录。
- 上传照片后能生成识别文本和判分结果。
- 低置信度题目可让用户确认。
- 错题跨设备同步。

## 阶段 3：AI 教研能力

目标：让系统从“能用”变成“好用”。

工作项：

- 课件生成接入大模型。
- 题目生成接入大模型和规则校验。
- 解析生成接入大模型。
- 错因诊断和个性化复习计划。
- 教师端审核题目和课件。

验收：

- AI 题目必须可自动验证答案。
- 解析包含考点、步骤、易错点和同类题。
- 错题复习能按掌握状态调整题目比例。
- 教研人员可以审核和发布内容。

## 阶段 4：商业化扩展

目标：从小学数学人教版扩展到更多教材和学科。

工作项：

- 扩展苏教版、北师大版等教材版本。
- 扩展语文、英语等学科。
- 增加班级、教师、家校沟通。
- 增加学情报告和学习路径。
- 增加支付、会员、机构管理。

验收：

- 多教材版本可配置。
- 多学科共用题库、错题和批改框架。
- 教师可管理班级测验和报告。
