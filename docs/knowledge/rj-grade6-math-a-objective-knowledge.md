## 1. 确定位置

### 客观知识点

- 数对可用两个数表示平面中点的位置。
- 数对中通常第一个数表示列，第二个数表示行。
- 在方格图中，列和行需要先确定方向和起点。
- 位置可用方向和距离共同确定。
- 用方向和距离描述位置时，需要确定观测点。
- 比例尺或单位长度可用于把实际距离转化为图上距离。
- 路线描述可由多个位置、方向和距离组成。

### 可出题技能点

- 根据数对在方格图中找点。
- 写出方格图中点的数对。
- 判断数对表示的位置变化。
- 根据方向和距离确定位置。
- 描述从一个点到另一个点的路线。
- 根据比例关系计算图上距离或实际距离。
- 在平面图中标出目标位置。

### 题型标签

- 数对定位
- 方格图
- 列和行
- 方向距离
- 观测点
- 路线描述
- 图上距离

### 易错点

- 数对中列和行顺序写反。
- 没有确定观测点就描述方向。
- 图上距离和实际距离混淆。
- 方向角或方向名称判断错误。

## 2. 分数乘法

### 客观知识点

- 分数乘整数可以表示几个相同分数相加。
- 分数乘整数可用分子乘整数，分母不变，再约分。
- 分数乘分数可用分子相乘作分子，分母相乘作分母。
- 计算分数乘法时可先约分再相乘。
- 求一个数的几分之几可以用乘法。
- 单位“1”表示被平均分或被比较的整体。
- 连续求一个数的几分之几可用连乘或分步计算。
- 分数乘法可解决面积、长度、数量等实际问题。

### 可出题技能点

- 计算分数乘整数。
- 计算分数乘分数。
- 先约分再计算。
- 求一个数的几分之几。
- 判断单位“1”。
- 根据线段图列分数乘法算式。
- 解决连续分数乘法问题。
- 比较分数乘法结果与原数大小。

### 题型标签

- 分数乘整数
- 分数乘分数
- 约分计算
- 求几分之几
- 单位1
- 连续分数乘法
- 线段图分析

### 易错点

- 把分数加法规则用于分数乘法。
- 约分对象选错。
- 单位“1”判断错误。
- 连续求几分之几时只乘一次。

## 3. 分数除法

### 客观知识点

- 乘积是 1 的两个数互为倒数。
- 求一个非 0 数的倒数，可交换分子和分母位置。
- 除以一个非 0 数等于乘这个数的倒数。
- 分数除法可转化为分数乘法计算。
- 已知一个数的几分之几是多少，求这个数，可用除法或方程思路。
- 分数混合运算遵循整数混合运算顺序。
- 含括号的分数混合运算先算括号内。
- 分数乘除应用题常借助线段图分析单位“1”和比较关系。

### 可出题技能点

- 判断两个数是否互为倒数。
- 求整数、分数、小数的倒数。
- 计算分数除以整数。
- 计算整数除以分数。
- 计算分数除以分数。
- 解决已知几分之几求整体的问题。
- 计算分数乘除混合算式。
- 根据线段图列式或补充条件。

### 题型标签

- 倒数
- 分数除法
- 除以分数
- 已知部分求整体
- 分数混合运算
- 单位1分析
- 方程思路

### 易错点

- 0 没有倒数。
- 除法转乘法时没有乘倒数。
- 被除数和除数颠倒。
- 单位“1”找错导致列式相反。

## 4. 生活中的负数

### 客观知识点

- 正数和负数可表示具有相反意义的量。
- 0 既不是正数，也不是负数。
- 温度、海拔、盈亏、收入支出、方向移动等可用正负数表示。
- 数轴上，正数在 0 的一侧，负数在另一侧。
- 在数轴上，右边的数大于左边的数。
- 正负数比较可借助数轴或实际意义。
- 相反意义的量需要先确定基准。

### 可出题技能点

- 读写正数和负数。
- 判断实际情境中正负数表示的意义。
- 在数轴上表示正负数。
- 比较正数、负数和 0 的大小。
- 根据基准判断某个量应记为正数还是负数。
- 解决温度、海拔、盈亏等情境题。

### 题型标签

- 正负数意义
- 数轴表示
- 正负数比较
- 相反意义的量
- 生活应用
- 基准量

### 易错点

- 认为带负号的数一定比 0 大。
- 没有确定基准就写正负号。
- 比较负数大小时只看绝对值大小。

## 5. 圆

### 客观知识点

- 圆是平面上一类到定点距离相等的点组成的图形。
- 圆心决定圆的位置。
- 半径决定圆的大小。
- 直径通过圆心，两端在圆上。
- 同一个圆内，直径是半径的 2 倍。
- 圆有无数条半径和直径。
- 圆周率表示圆周长与直径的比值，通常用 π 表示。
- 圆的周长公式：C = πd 或 C = 2πr。
- 圆的面积可通过转化为近似长方形推导，公式为 S = πr²。
- 半圆、扇形、圆环等图形可由圆的部分或组合形成。
- 圆环面积等于大圆面积减小圆面积。
- 组合图形面积可通过分割、补全或相减求解。

### 可出题技能点

- 识别圆心、半径、直径。
- 根据半径求直径，或根据直径求半径。
- 画指定半径或直径的圆。
- 计算圆的周长。
- 计算圆的面积。
- 计算半圆周长或面积。
- 计算圆环面积。
- 解决与圆形场地、车轮、跑道、圆形物体有关的问题。
- 判断组合图形中圆的部分面积。

### 题型标签

- 圆的认识
- 圆心半径直径
- 圆周率
- 圆周长
- 圆面积
- 半圆
- 圆环
- 扇形
- 组合图形面积

### 易错点

- 把半径和直径混淆。
- 圆周长和圆面积公式混用。
- 半圆周长漏加直径。
- 圆环面积用大半径减小半径后再平方。
- 组合图形重复计算或漏算。

## 综合实践：体育中的数学

### 客观知识点

- 运动场、跑道、比赛安排可涉及长度、周长、速度、时间和统计数据。
- 环形跑道中的弯道可与圆或半圆的周长相关。
- 比赛成绩可用时间、距离、速度等数据比较。
- 赛程安排需要考虑轮次、人数、场次和公平性。
- 体育数据可用表格整理并进行比较分析。

### 可出题技能点

- 计算跑道相关长度。
- 比较运动成绩。
- 根据速度、时间、路程解决问题。
- 用表格整理比赛数据。
- 设计简单赛程或判断安排是否合理。
- 分析体育情境中的数量关系。

### 题型标签

- 跑道问题
- 体育数据
- 路程速度时间
- 赛程安排
- 表格分析
- 圆周长应用

### 易错点

- 混淆时间越短成绩越好和数值越大越好。
- 跑道弯道长度计算遗漏圆周关系。
- 赛程安排中重复或遗漏比赛场次。

## 6. 百分数

### 客观知识点

- 百分数表示一个数是另一个数的百分之几。
- 百分数又叫百分率或百分比。
- 百分数的分母固定为 100，通常用 `%` 表示。
- 百分数可以和分数、小数互相转化。
- 求百分率通常用比较量除以单位“1”的量，再化成百分数。
- 常见百分率包括出勤率、合格率、发芽率、命中率、增长率等。
- 求一个数的百分之几可用乘法。
- 已知一个数的百分之几是多少，求这个数可用除法或方程思路。
- 利息、利率、本金、时间之间存在数量关系。
- 百分数应用题需要明确单位“1”。
- 折扣、增加百分之几、减少百分之几都属于百分数应用。

### 可出题技能点

- 读写百分数。
- 分数、小数、百分数互化。
- 比较百分数、分数、小数大小。
- 求百分率。
- 求一个数的百分之几。
- 已知百分数对应量求单位“1”。
- 解决增长率、减少率问题。
- 解决折扣、利率、税率等生活问题。
- 根据统计表或条形图计算百分数。

### 题型标签

- 百分数意义
- 百分数互化
- 百分率
- 单位1
- 百分数应用题
- 增长率
- 折扣
- 利率
- 统计百分比

### 易错点

- 把百分数当作具体数量并带单位。
- 百分数、分数、小数互化位置错误。
- 单位“1”判断错误。
- 增加百分之几和增加到百分之几混淆。
- 利息、利率、本金、时间关系混淆。

## 综合实践：水是生命之源

### 客观知识点

- 水资源数据可用百分数、统计表和统计图表示。
- 百分数可用于表示占比、节约率、增长率或减少率。
- 节水情境中常涉及用水量、节水量、总量和百分率。
- 数据比较需要统一单位和统计口径。
- 根据统计数据可以进行简单推算和方案比较。

### 可出题技能点

- 读取水资源相关统计数据。
- 计算占比或节约率。
- 根据百分数求用水量或节水量。
- 比较不同方案的节水效果。
- 用表格或图表整理数据。
- 根据数据作出合理数学判断。

### 题型标签

- 水资源数据
- 百分数统计
- 节水率
- 数据比较
- 方案分析
- 生活应用

### 易错点

- 统计数据单位不统一。
- 占比和总量混淆。
- 百分率计算时比较量和总量颠倒。

## 7. 复习与关联

### 客观知识点

- 确定位置属于图形与位置领域。
- 分数乘除法和百分数属于数与运算领域。
- 生活中的负数属于数的扩展和实际应用。
- 圆属于图形与几何领域。
- 体育和水资源综合实践连接测量、统计、百分数和几何应用。
- 综合问题常需要先确定单位“1”、图形关系或数量关系。
- 估算、画图、线段图、数轴和表格可帮助解决问题。

### 可出题技能点

- 判断题目所属知识领域。
- 将综合题拆成分数、百分数、圆或位置问题。
- 用线段图分析单位“1”。
- 用公式解决圆相关综合问题。
- 根据统计数据解决百分数问题。
- 用数轴解释正负数关系。
- 检查结果是否符合实际情境。

### 题型标签

- 全册复习
- 分数百分数综合
- 圆综合
- 位置综合
- 负数应用
- 统计数据分析

### 易错点

- 单位“1”、比较量和对应量混淆。
- 圆的周长、面积、半径、直径关系混用。
- 负数和百分数在实际情境中意义判断错误。
