# 小学数学人教版 MVP PRD

## 1. 产品定位

面向小学生、家长和一线老师的同步数学学习工具。第一版只覆盖“小学数学 + 人教版 + 3-6 年级”的 MVP 场景，让用户选择年级、册别和单元后，可以快速完成“学、练、批、讲、复测”的学习闭环。

参考 `hezkvectory/hermes-edu-skills` 的能力组织方式：把教材同步、拍照答疑、错题复盘、每日练习等拆成可组合的教育 Agent 工作流。本 MVP 不直接复制 Skill 文档，而是把这些工作流产品化为可操作模块。

## 2. 用户角色

### 学生

- 选择当前教材范围，生成知识点讲解和练习。
- 上传答题照片或录入答案，获得判分和逐题解析。
- 从错题库复习薄弱知识点。

### 家长

- 给孩子生成每日/每周练习。
- 查看错题、掌握度和下一步复习建议。
- 用错题卷检验是否真正掌握。

### 老师/教研

- 按单元生成课件大纲、课堂例题和课后练习。
- 快速生成小测卷。
- 后续可扩展班级批改和学情报告。

## 3. MVP 范围

### 必须支持

1. 教材参数选择
   - 教材版本：人教版
   - 学科：小学数学
   - 年级：3-6 年级
   - 册别：上册/下册
   - 单元：MVP 内置原创样例单元

2. 知识点课件生成
   - 单元目标
   - 知识点拆解
   - 每个知识点展示可靠来源
   - 优先引用官方教材入口和课程标准作为范围依据
   - 导入问题
   - 讲解页
   - 例题页
   - 课堂练习
   - 小结与作业
   - 支持导出 Markdown

3. 同步练习/试卷生成
   - 按单元、知识点、难度、题量生成题目
   - 每题包含答案、分值、解析和考点
   - 难度至少支持：基础、提高、挑战
   - 按知识点轮转生成，避免同一题型堆叠过多
   - 每题解析包含审题、建模、计算、作答、易错点和检查方法

4. 拍照批改
   - 支持上传照片预览
   - 支持 OCR 识别文本区/手动校正区
   - 支持按题号解析学生答案
   - 自动判分并展示总分、正确率和逐题结果

5. 错题库
   - 自动保存错题
   - 保存学生答案、正确答案、解析、知识点、单元、时间
   - 支持标记已掌握
   - 支持从错题库随机生成试卷

6. 周期测验
   - 支持每日/每周/每月频率配置
   - 支持题量和错题占比设置
   - 可一键生成周期测验卷

### 暂不支持

- 直接复刻教材原文和课本图片
- 商业题库接入
- 真正手写 OCR 模型
- 作文/证明题/开放题自动高可信评分
- 班级、学校、教师后台
- 支付、账号、权限、家校沟通

## 4. 核心流程

### 学习流程

1. 用户选择年级、册别、单元。
2. 系统展示知识点和课件大纲。
3. 用户生成同步练习。
4. 学生答题。
5. 用户上传照片或输入答案。
6. 系统判分并逐题讲解。
7. 错题进入错题库。
8. 后续从错题库生成复习卷。

### 周期测验流程

1. 家长/老师设置测验频率、题量、错题占比。
2. 系统根据当前单元和错题库组卷。
3. 学生完成测验。
4. 系统判分、解析并更新错题库。

## 5. 内容原则

- MVP 内容只用原创知识点摘要和原创题目。
- 不存储教材原文、课本插图、教辅原题。
- 正式上线前需要完成教材目录授权/自建教研校验。
- 所有题目都要带知识点标签、难度、答案、解析和评分规则。
- 课件知识点必须显示来源。官方教材只能作为范围核验和合法入口，不复制原文、插图和原题。
- 同步出题必须覆盖知识点而不是堆题，同一题型数量应受限。
- 解析必须详细，至少包含步骤、易错点和检查方法。

## 6. 验收标准

- 用户能选择人教版小学数学 3-6 年级范围。
- 用户能生成至少 5 道同步练习。
- 用户能录入或模拟识别答案并获得判分结果。
- 错题能持久化到浏览器本地存储。
- 用户能从错题库生成一套复习卷。
- 用户能导出课件 Markdown。
- 整个 MVP 不依赖后端服务即可跑通核心体验。
