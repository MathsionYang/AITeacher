# 小学数学人教版 MVP PRD

## 1. 产品定位

面向小学生、家长和一线老师的同步数学学习工具。第一版只覆盖“小学数学 + 人教版 + 3-6 年级”的 MVP 场景，让用户选择年级、册别和单元后，可以快速完成“学、练、批、讲、复测”的学习闭环。

参考 `hezkvectory/hermes-edu-skills` 的能力组织方式：把教材同步、拍照答疑、错题复盘、每日练习等拆成可组合的教育 Agent 工作流。本 MVP 不直接复制 Skill 文档，而是把这些工作流产品化为可操作模块。

## 2. 用户角色

### 学生

- 选择当前教材范围，查看已生成或已导入的知识点课件。
- 在同步出题页面完成当前单元练习，直接填写答案并获得判分和逐题解析。
- 从错题库复习薄弱知识点，并通过错题卷或周期测验检验掌握情况。

### 家长

- 给孩子生成每日/每周练习。
- 查看错题、掌握度、成绩趋势和下一步复习建议。
- 用错题卷检验孩子是否真正掌握。

### 老师/教研

- 按单元生成课件、课堂例题、同步练习和小测卷。
- 审核课件中的知识点、来源、图形表达和例题是否准确。
- 审核 AI 出题是否越过当前单元边界、题型是否重复、解析是否足够清晰。
- 导出课件 PDF/Markdown/PPTX/JSON 和练习 JSON，用于授课、备份或教研流转。
- 查看已完成题目数量、错题数量、成绩趋势和薄弱知识点。
- 通过教师端管理班级、切换年级/学科/册别、添加或移除学生。

### 端划分策略

- MVP 当前先开放教师端：`login.html` 保留教师/学生登录按钮，但学生登录只提示暂未开放。
- 教师端负责生成、审核、导入导出、班级管理、学生名册和本地学情查看。
- 学生端等 Go 或 Java 后端接入账号、权限、作业、学生个人练习记录和班级报告后再开放。

## 3. MVP 范围

### 必须支持

1. 教材参数选择
   - 教材版本：人教版
   - 学科：小学数学
   - 年级：3-6 年级
   - 册别：上册/下册
   - 单元：MVP 内置原创样例单元
   - 当前班级：教师可切换班级，并由班级默认年级/学科/册别同步侧栏范围

2. 知识点课件生成
   - 单元目标
   - 知识点拆解
   - 每个知识点展示可靠来源
   - 优先引用官方教材入口和课程标准作为范围依据
   - 课件结构在同一单元下保持大致稳定，避免每次生成风格大幅漂移
   - 每页优先使用图形、表格、数轴、流程或动画表达，图形化必须帮助理解知识点、数量关系或解题步骤，而不是装饰美化
   - 导入问题
   - 讲解页
   - 例题页
   - 课堂练习
   - 小结与作业
   - 课件区域默认空白，支持导入历史课件
   - 点击 AI 生成/重新生成课件后展示进度动画，全部生成并校验后再展示
   - 支持单独授课全屏模式，可直接投屏讲课，使用键盘翻页
   - 支持人工审核编辑并保存审核稿
   - 支持导出 JSON、PDF、Markdown 和 PPTX
   - PPTX 由结构化 PPT 方案本地生成，PPT 制作 Agent 只负责排版方案和讲解顺序

3. 同步练习/试卷生成
   - 同步出题区域默认空白，支持导入历史练习
   - 按单元、知识点、难度、题量生成题目
   - 出题范围不得超过当前单元的客观知识点边界
   - 同步练习只能出现用户当前选择单元的知识点练习题，不允许从其他单元补题或混题
   - 每次题目固定 10 题，并覆盖当前单元全部知识点
   - 每套卷总分固定为 100 分
   - 每题包含答案、分值、解析和考点
   - 难度至少支持：基础、提高、挑战
   - 按知识点轮转生成，避免同一题型堆叠过多
   - 每题解析包含审题、建模、计算、作答、易错点和检查方法
   - 点击 AI 生成/重新生成练习后展示进度动画，全部题目生成并校验后再展示
   - 支持导出同步练习 JSON，包含题目、答案草稿和最近判分结果
   - 支持在同步出题页面直接填写答案、判分并生成逐题解析
   - 同步出题页判分结果同步到拍照批改页面

4. 拍照批改
   - 支持上传照片预览
   - 支持 OCR 识别文本区/手动校正区
   - 支持按题号解析学生答案
   - 自动判分并展示总分、正确率和逐题结果
   - 接收同步出题页直接填写的答案和判分结果
   - 低于 60 分生成随机鼓励话语图片
   - 60-79 分生成肯定类图片，例如奖状
   - 80-94 分触发撒花特效
   - 95 分及以上触发卡通人物走上领奖台领取奖杯动画
   - 判分结果保存到本地历史成绩
   - 根据历史成绩生成趋势图，并分析薄弱知识点掌握程度

5. 错题库
   - 自动保存错题
   - 保存学生答案、正确答案、解析、知识点、单元、时间
   - 展示已完成题目数量和当前错题数量
   - 支持标记已掌握
   - 支持从错题库移除错题
   - 支持从错题库随机生成试卷

6. 周期测验
   - 支持每日/每周/每月频率配置
   - 支持题量和错题占比设置
   - 可一键生成周期测验卷

7. 教师端与班级管理
   - 登录页保留教师/学生两个入口，当前只开放教师端。
   - 本地默认教师账号为 `teacher / teacher123`。
   - 教师端左侧导航固定为：导学课件、同步出题、错题库、周期测验、班级管理、系统设置。
   - 教师可新增/删除班级；删除班级前需先清空该班学生。
   - 教师可在当前班级下新增/删除学生。
   - 系统设置集中管理模型与 Agent、本地数据和拍照/OCR 校正入口。
   - 本地备份包含账号、班级、学生、课件、出题、提交、错题和成绩数据。
   - SQLite 迁移 schema 预留后端账号表、班级表、学生表、课件表、试卷表、题目表、提交表、OCR 记录表。

### 暂不支持

- 直接复刻教材原文和课本图片
- 商业题库接入
- 真正手写 OCR 模型
- 作文/证明题/开放题自动高可信评分
- 学生端登录、学生独立练习空间、学校管理后台
- 支付、账号、权限、家校沟通

## 4. 核心流程

### 学习流程

1. 用户选择年级、册别、单元。
2. 系统展示知识点和课件大纲。
3. 用户生成同步练习。
4. 学生答题。
5. 用户上传照片或输入答案。
6. 系统判分并逐题讲解。
7. 错题进入错题库。
8. 后续从错题库生成复习卷。

### 周期测验流程

1. 家长/老师设置测验频率、题量、错题占比。
2. 系统根据当前单元和错题库组卷。
3. 学生完成测验。
4. 系统判分、解析并更新错题库。

## 5. 内容原则

- MVP 内容只用原创知识点摘要和原创题目。
- 不存储教材原文、课本插图、教辅原题。
- 正式上线前需要完成教材目录授权/自建教研校验。
- 所有题目都要带知识点标签、难度、答案、解析和评分规则。
- 课件知识点必须显示来源。官方教材只能作为范围核验和合法入口，不复制原文、插图和原题。
- 同步出题必须覆盖知识点而不是堆题，同一题型数量应受限。
- 同步出题、错题卷和周期测验都不能越过当前单元知识点边界。
- 课件图形必须承担教学解释功能，优先呈现整体与部分、数量关系、公式对应、数轴位置、数据比较或解题流程。
- 解析必须详细，至少包含步骤、易错点和检查方法。

## 6. 验收标准

- 教师能从 `login.html` 登录教师端，学生入口保留且提示暂未开放。
- 教师能选择人教版小学数学 3-6 年级范围，并切换班级、添加/删除学生。
- 用户能生成至少 5 道同步练习。
- 用户生成的试卷固定 10 题，覆盖当前单元全部知识点，且总分固定为 100 分。
- 用户能录入或模拟识别答案并获得判分结果。
- 用户判分后能看到分数段反馈、成绩保存、趋势图和薄弱知识点分析。
- 错题能持久化到浏览器本地存储。
- 用户能从错题库生成一套复习卷。
- 用户能进入授课全屏模式讲解课件，也能审核编辑课件，并导出课件 PDF/Markdown/PPTX。
- 整个 MVP 不依赖后端服务即可跑通核心体验。
