# 课题通 EduForge 小学数学人教版教师端 MVP PRD

## 1. 产品定位

课题通 EduForge 是部署在客户电脑上的教师备课与出题工具。当前只覆盖：

- 教材版本：人教版
- 学科：小学数学
- 年级：3-6 年级
- 册别：上册
- 使用者：教师

当前版本不做学生端、班级管理、学生管理和服务器端作业流。
当前版本也不做学生作答、自动判分、拍照批改、错题库和成绩趋势，只帮助教师生成试题，教师人工审核无误后导出使用。

## 2. 一级模块

左侧导航只保留四项：

1. 课件生成
2. 同步出题
3. 周期测验出题
4. 系统设置

左侧导航固定在视窗内，不随右侧内容滚动。

## 3. 系统设置

系统设置只保留：

- 学科：当前固定数学
- 年级：3-6 年级
- 册别：当前知识包覆盖上册
- 模型设置：provider、model、Base URL、本地代理/直连临时 Key

单元不放在系统设置中。课件生成、同步出题、周期测验出题页面各自都有单元选择器，任一页面修改单元后同步到其他页面。

## 4. 课件生成

- 默认先显示当前单元历史课件。
- 必须先选择单元，再生成课件。
- 课件由当前单元客观知识点作为输入生成，不复制教材原文、课本例题和商业题库内容。
- 课件呈现使用 MarkdownFlow 读模式。
- 图形化用于解释知识点，不做纯装饰。
- 支持审核编辑、保存审核稿、授课全屏、PDF、Markdown、PPTX、JSON 导入导出。
- 生成完成前显示进度动画，完成并校验后再展示内容。

## 5. 同步出题

- 默认先显示当前单元历史出题记录。
- 课件页选定单元后，同步出题页自动使用该单元；同步出题页仍可修改单元，修改后反向同步到其他模块。
- 每次固定生成 10 道题，总分 100 分。
- 每次必须覆盖本单元全部知识点。
- 题目范围不能超过当前单元知识点边界。
- 题型优先选择题、填空题、计算填空题、单位换算填空题等标准答案题。
- 开放题、说明理由题、作图题、判断改错题等不进入当前出题范围。
- 同一题型不堆叠过多。
- 每题包含题干、答案、分值、知识点和必要的教师审核提示。
- 支持导出空白卷 PDF、含答案 PDF 和 JSON。
- 不支持在页面内填写学生答案，不做自动判分和逐题解析。

## 6. 周期测验出题

- 默认先显示当前单元历史测验卷。
- 按当前单元固定生成 10 道题，总分 100 分。
- 当前 MVP 不混入跨单元题。
- 支持频率设置：每日、每周、每月。
- 支持导出空白卷 PDF 和含答案 PDF。

## 7. 模型与 Agent 边界

大模型与 Agent 只用于需要理解、生成、诊断、规划的环节：

- 导学课件生成
- 同步题生成
- PPT 排版方案
- 题目质量检查和教师审核辅助
- OCR/答案语义理解仅作为后续扩展，不进入当前 MVP

题量、分值、单元边界、题型过滤、答案可判定性、导出版本号和审核状态由规则引擎和结构化数据控制。

## 8. 本地数据

MVP 使用 localStorage。数据层按后续 JSON/SQLite 迁移设计：

- 账号信息
- 教师设置
- 模型配置
- 课件记录
- 同步出题记录
- 周期测验记录
- 题目记录
- 生成记录
- 旧版判分/OCR 字段可作为迁移兼容保留，但不是当前 MVP 必需数据

不再保留班级、学生、学生端练习记录作为当前 MVP 必需数据。

## 9. 验收标准

- 教师能从 `login.html` 使用演示账号 `teacher001 / 123456` 登录。
- 登录后只看到四个一级模块。
- 系统设置只显示学科、年级、册别和模型设置。
- 课件页选择单元后，同步出题和周期测验页自动同步该单元。
- 同步出题页和周期测验页仍可修改单元，并同步回其他模块。
- 同步出题固定 10 题、100 分、覆盖本单元全部知识点。
- 同步出题和周期测验均可导出空白卷 PDF 与含答案 PDF。
- 左侧导航不随右侧页面滚动。
