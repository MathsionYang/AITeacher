# 课题通 EduForge 小程序 UI 设计方案

> 基于 Web 端产品 PRD 与设计系统，适配微信小程序交互范式  
> 设计日期：2026-07-16 | 设计师：UI Designer

---

## 1. 设计理念

### 1.1 核心原则

| 原则 | 说明 |
|------|------|
| **移动优先** | 从桌面端 320px 侧栏 + 大工作区，转为 375px 单列竖屏，信息密度降低，操作路径缩短 |
| **触控友好** | 所有可交互元素 ≥ 44×44px，间距 ≥ 8px，底部 TabBar 适配安全区域 |
| **品牌延续** | 保持 Web 端 Teal + Amber 双色系，组件视觉语言一致 |
| **极简流程** | 每个页面聚焦一个核心任务，减少认知负担，3 步内完成主要操作 |
| **即时反馈** | AI 生成过程用全屏加载遮罩 + 进度文案，避免用户焦虑 |

### 1.2 与 Web 端的差异

| 维度 | Web 端 | 小程序端 |
|------|--------|----------|
| 导航 | 左侧固定侧栏（4项） | 底部 TabBar（4项） |
| 布局 | 双栏（侧栏+工作区） | 单列竖屏 |
| 操作密度 | 高（多按钮并排） | 低（主操作突出，次要操作收进菜单） |
| 课件展示 | 3列网格 + MarkdownFlow 阅读器 | 单列卡片流 + 全屏授课模式 |
| 出题展示 | 表格 + 折叠面板 | 卡片列表 + 点击展开答案 |
| 导出 | 浏览器下载 | 小程序保存/分享 |
| 设置 | 独立 Tab 页 | 合并进「我的」二级页面 |

## 2. 信息架构

### 2.1 页面层级

```
底部 TabBar
├── 首页 / 工作台（Tab 1）
│   ├── 问候语 + 教材范围卡片
│   ├── 快捷入口 × 3（课件/出题/测验）
│   ├── 数据统计 × 3
│   └── 最近使用列表
│
├── 课件生成（Tab 2）
│   ├── 单元选择器
│   ├── AI 生成按钮
│   ├── 知识点标签云
│   ├── 课件幻灯片列表
│   │   ├── [子页] 全屏授课模式
│   │   └── [子页] 审核编辑
│   └── 历史课件列表
│
├── 出题中心（Tab 3）
│   ├── 模式切换：同步出题 / 周期测验
│   │
│   ├── 同步出题
│   │   ├── 单元 + 难度选择
│   │   ├── AI 生成按钮
│   │   ├── 试卷摘要（题量/总分/知识点）
│   │   ├── 题目卡片列表（答案折叠）
│   │   └── 导出（空白卷/含答案 PDF）
│   │
│   └── 周期测验
│       ├── 单元 + 频率 + 题量
│       ├── AI 生成按钮
│       └── 历史测验卷列表
│
└── 我的（Tab 4）
    ├── 个人信息（头像/姓名/认证状态）
    ├── 教材范围设置 → [子页] 学科/年级/册别
    ├── AI 模型状态卡
    ├── 我的课件 / 出题记录 / 测验历史
    ├── 模型设置 → [子页] 服务商/模型/URL/Key
    ├── 导入/导出数据
    ├── 关于
    └── 退出登录
```

### 2.2 导航规则

- **全局单元同步**：任一页面修改单元后，其他页面自动同步
- **页面深度**：最深 3 级（Tab → 列表 → 详情）
- **返回方式**：左上角箭头 + 系统手势返回
- **无模态阻断**：除加载遮罩外不使用全屏弹窗

## 4. 核心页面设计

### 4.1 首页 / 工作台

**设计目标**：用户进入即看到核心数据与快捷操作，3 秒内触达任一功能。

**页面结构**：
1. **顶部品牌区**（渐变 Teal 背景）
   - 问候语 + 教师姓名 + 头像
   - 教材范围卡片（年级/册别/学科），点击切换
   
2. **快捷入口区**（3列等宽卡片，悬浮在品牌区下方）
   - 课件生成（Teal 图标）
   - 同步出题（Blue 图标）
   - 周期测验（Amber 图标）
   
3. **数据统计区**（3列等宽统计卡）
   - 历史课件数 / 已出题目数 / 测验卷数
   - 左侧 3px 色条区分
   
4. **最近使用列表**
   - 按时间倒序，最多展示 5 条
   - 左侧图标区分类型（课件/出题/测验）
   - 右侧箭头进入详情

**交互说明**：
- 下拉刷新：更新统计数据和最近记录
- 快捷入口点击 → 跳转对应 Tab 页
- 教材范围卡片点击 → 弹出底部选择器

### 4.2 课件生成

**设计目标**：选单元 → 一键生成 → 预览导出，全流程在单页完成。

**页面结构**：
1. **单元选择器**（白底卡片）
   - 显示当前单元名称 + 年级册别
   - 点击弹出底部 Unit Picker
   
2. **AI 生成按钮**（全宽渐变按钮，48px 高）
   - 点击后全屏加载遮罩
   - 加载文案：「AI 正在根据知识点组织课件内容…」
   
3. **知识点标签云**
   - 展示当前单元全部知识点
   - 圆角 Pill 标签，自动换行
   
4. **课件幻灯片列表**
   - 每张卡片：序号 + 标题 + 内容摘要 + 可视化区
   - 底部操作栏：授课 / 编辑 / 导出
   - 左侧 3px 品牌色条

**交互说明**：
- 授课按钮 → 进入全屏幻灯片模式（横屏支持）
- 编辑按钮 → 进入行内编辑（contenteditable）
- 导出按钮 → 底部弹出导出选项（PDF/PPTX/Markdown）
- 历史按钮（右上角）→ 跳转历史课件列表

### 4.3 出题中心

**设计目标**：双模式切换（同步出题 / 周期测验），教师审核为核心。

**页面结构**：

**同步出题模式**：
1. 单元选择器
2. 难度筛选条（基础/提高/挑战，三选一）
3. AI 生成按钮
4. 试卷摘要条（题量 10 / 总分 100 / 知识点数）
5. 题目卡片列表
   - 题号色块 + 题型标签 + 分值
   - 题干 + 选项（选择题）/ 填空线（填空题）
   - 答案默认折叠，点击展开
   - 答案区绿色背景，含教师审核提示
6. 更多操作（右上角菜单）：导出空白卷/含答案PDF/JSON

**周期测验模式**：
1. 单元选择器
2. 频率选择器（每日/每周/每月，三列等宽）
3. 题量滑块（10-100，带实时数字显示）
4. AI 生成按钮
5. 历史测验卷列表

**交互说明**：
- 同步出题固定 10 题 / 100 分，不可修改
- 周期测验题量通过滑块调整，实时显示数字
- 答案展开支持逐题展开和全局展开
- 导出操作收进右上角「更多」菜单

### 4.4 我的 / 设置

**设计目标**：个人信息 + 全局设置 + 数据管理，分组清晰。

**页面结构**：
1. **个人资料头部**（渐变 Teal 背景）
   - 头像 + 姓名 + 认证状态
   
2. **教材范围条**（白底卡片）
   - 当前设置：年级/册别/学科
   - 点击进入设置页
   
3. **AI 模型状态卡**（品牌色渐变背景）
   - 模型名称 + 连接模式
   - 绿色状态点表示已连接
   
4. **菜单组 1：内容管理**
   - 我的课件（12份）
   - 出题记录（36题）
   - 测验历史（5份）
   
5. **菜单组 2：系统设置**
   - 模型设置（已配置）
   - 导入/导出数据
   - 关于课题通（v1.0.0）
   
6. **退出登录**（红色文字，居中）

### 5.2 主按钮

| 状态 | 背景 | 文字 | 阴影 |
|------|------|------|------|
| 默认 | linear-gradient(135deg, #0D9488, #14B8A6) | #FFFFFF | 0 4px 14px rgba(13,148,136,0.3) |
| 按下 | 同上 | #FFFFFF | 0 2px 8px rgba(13,148,136,0.2) |
| 加载中 | #94A3B8 | #FFFFFF | none |
| 禁用 | #E2E8F0 | #94A3B8 | none |

- 高度：48px
- 圆角：12px
- 字号：16px / 700
- 按下反馈：scale(0.97)

### 5.3 卡片

| 类型 | 圆角 | 阴影 | 边框 | 左色条 |
|------|------|------|------|--------|
| 内容卡片 | 14px | shadow-sm | none | 可选 3px 品牌色 |
| 统计卡片 | 12px | shadow-sm | none | 3px 多色 |
| 题目卡片 | 14px | shadow-sm | none | none |
| 设置卡片 | 14px | shadow-sm | none | none |

### 5.4 加载遮罩

- 全屏半透明白色背景（rgba(255,255,255,0.95)）
- 中心 Spinner（44px，品牌色旋转动画）
- 下方文案：标题 16px + 说明 13px
- 遮罩期间禁止底层交互

## 6. 交互规范

### 6.1 转场动画

| 场景 | 动画 | 时长 | 缓动 |
|------|------|------|------|
| 页面进入 | 从右侧滑入 | 300ms | ease-out |
| Tab 切换 | 内容淡入 | 200ms | ease-out |
| 卡片点击 | scale(0.97) | 100ms | ease-out |
| 答案展开 | 高度展开 + 淡入 | 250ms | ease-out |
| 底部弹窗 | 从底部滑入 | 300ms | ease-out |

### 6.2 触控规范

- 最小触控区：44×44px
- 按钮间距：≥ 8px
- 列表项高度：≥ 56px
- 滑块触控区：扩展至 44px 高

### 6.3 无障碍

- 所有图标配合文字标签
- 颜色对比度 ≥ 4.5:1（WCAG AA）
- 支持系统字体放大至 200%
- 焦点可见（focus-visible outline）

## 7. 适配说明

### 7.1 屏幕适配

| 设备 | 宽度 | 策略 |
|------|------|------|
| iPhone SE | 320px | 内容区域适当压缩，快捷入口改为 2 列 |
| iPhone 15 | 393px | 标准设计宽度 |
| iPhone 15 Pro Max | 430px | 内容居中，最大宽度 414px |
| Android 主流 | 360px | 标准适配 |
| Android 大屏 | 412px | 内容居中 |

### 7.2 技术实现

- 单位：rpx（750rpx = 屏幕宽度）
- 布局：Flexbox 为主
- 字体：系统默认字体栈
- 存储：wx.setStorage / wx.getStorage
- 导出：云函数生成 PDF 或前端 Canvas 方案
- 网络：wx.request 调用本地代理或云端 API
