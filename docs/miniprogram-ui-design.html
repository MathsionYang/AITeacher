字体规范

  • 标题 H1: 20px / 700
  • 标题 H2: 17px / 700
  • 标题 H3: 15px / 600
  • 正文 Body: 14px / 400
  • 辅助 Caption: 12px / 400
  • 数字 Number: 24px / 800

间距系统

  • 基础单位: 4px (1rpx ≈ 0.5px)
  • 组件内间距: 12-16px
  • 组件间间距: 8-12px
  • 页面边距: 16px
  • 区块间距: 16-24px
  • 圆角: 8/12/14/24px

交互规范

  • 最小触控区: 44×44px
  • 按钮高度: 48px (主) / 40px (次)
  • 点击反馈: scale(0.97)
  • 转场动画: 200ms ease-out
  • 下拉刷新: 系统默认
  • 加载态: Spinner + 文字提示

导航规范

  • 底部 Tab: 4 个一级入口
  • 页面层级: 最深 3 级
  • 返回: 左上角箭头 + 系统返回
  • 状态栏: 适配 iOS/Android
  • 安全区域: 底部 34px
  • 顶部导航: 居中标题 17px

流程 步骤 用户操作 系统反馈 注意事项
课件生成 1 选择单元（默认当前单元） 展示本单元知识点标签 单元切换全局同步
2 点击「AI 生成课件」 全屏加载动画 + 进度文案 生成期间不可重复点击
3 等待生成完成 展示课件幻灯片列表 完成后校验知识点覆盖
4 预览/审核编辑/授课 进入全屏授课或编辑模式 编辑需教师审核确认
5 导出 PDF/PPTX/Markdown 调用小程序保存/分享 大文件需等待提示
同步出题 1 选择单元 + 难度（基础/提高/挑战） 显示当前选择范围 默认上次选择
2 点击「AI 生成练习」 加载动画 + 文案提示 固定10题/100分
3 浏览题目列表 题目卡片展示题干+选项 答案默认折叠
4 点击「显示参考答案」 展开答案+教师审核提示 逐题展开/全局展开
5 导出空白卷/含答案PDF 生成PDF并保存 更多操作在右上角菜单
周期测验 1 选择单元 + 频率 + 题量(滑块) 实时显示题量数字 10-100题可调
2 点击「生成周期测验」 加载动画 尽量避开历史题干
3 保存测验设置 确认频率与题量配置 设置仅本地保存
4 查看历史测验卷 列表展示+导出操作 支持删除单条记录

适配项 说明 技术方案
屏幕适配 支持 iPhone SE ~ iPhone 15 Pro Max，Android 各品牌 rpx 响应式单位，flex 布局，max-width 约束
安全区域 底部 TabBar 适配 iOS Home Indicator env(safe-area-inset-bottom)，底部预留 34px
状态栏 适配 iOS 刘海屏 / Android 状态栏 navigationStyle: default，系统状态栏自动适配
深色模式 支持系统深色模式切换 CSS 变量 + @media (prefers-color-scheme: dark)
字体大小 支持系统字体放大（辅助功能） 使用 rem/rpx，避免固定 px
触控目标 所有可点击元素 ≥ 44×44px Wcag AA 标准，间距 ≥ 8px
网络状态 断网/弱网提示与重试 onNetworkStatusChange，全局 Toast 提示
本地存储 课件/出题/测验数据本地持久化 wx.setStorage / wx.getStorage，按单元分片
PDF 导出 生成 PDF 并保存到手机 云函数生成或前端 canvas → wx.saveFile
下拉刷新 首页/列表页支持下拉刷新 enablePullDownRefresh: true
