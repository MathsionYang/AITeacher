【标题】
小学数学课件怎么做才好看？这个AI课件生成器绝了✨

【正文】
做过课件的老师都知道：
PPT文字太多 → 学生不想看
图太少 → 知识点讲不透
网上找模板 → 还要改半天

今天深挖一下【课题通】的课件生成功能👇

🎯 生成流程超简单
1. 选年级+册别+单元
2. 点"AI生成"
3. 等进度条跑完
4. 课件直接出来，可以直接审核编辑

📖 课件结构固定且专业
每份课件都有完整骨架：
学习目标 → 情境导入 → 概念讲解 → 例题精讲 → 课堂练习 → 小结与作业
跟教研要求的流程完全对得上！

🎨 图形化是最大亮点
不是随便配个图，而是每个知识点都有对应的视觉表达：
🔸 分数概念 → 分数格逐步填充
🔸 小数比较 → 数轴标点移动
🔸 面积计算 → 面积模型拆解
🔸 购物问题 → 物品+价格标签图解
🔸 统计知识 → 柱状图增长动画

每个图形都在回答一个教学问题："整体怎么等分""长和宽怎么对应面积公式"

✏️ 审核编辑很方便
生成后可以直接改文字、调整内容
改完保存审核稿，下次还能继续用
支持导出：PDF / Markdown / PPTX / JSON
PPTX是本地生成的，不用装Office插件！

最厉害的是：同一单元重复生成，课件结构基本一致
不会每次出来都不一样，老师心里有底
